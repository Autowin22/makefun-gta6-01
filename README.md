Night Run: Port Solano — an original open-world crime game in the browser. Explore a sun-soaked coastal city on foot and by car: live traffic and pedestrians, cars to steal and drive, a five-star wanted level with police who pursue and bust you, four story missions from a harbor pickup to a bridge escape, melee and pistol combat, a HUD with a live minimap, and a save that persists between visits. Plain static files, no build step, no network.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 — or serve game/ with any static file server. `MAKEFUN_OUTPUT_DIR=out node main.ts` packages the game and its dossier into out/.
